# E-commerce Fashion Image Generation

把商品、模特与背景参考整理成可编辑英文提示词，并逐项检查服装保真。适用于服装替换、电商摄影和同款多视角。

## 安装与调用
复制 skills/e-commerce-fashion-image-generation/ 到支持 Skill 的助手技能目录，再调用：

    $e-commerce-fashion-image-generation
    请根据这组商品、模特和背景图准备五视角提示词。
    先列出保留项、替换项和无法核实的细节，不提交生图。

## 包含
- 参考角色核对和冲突处理。
- 可编辑英文提示词骨架。
- 首图检查、多视角商品证据与失败修正。
- 生成前数量/用量确认、未知请求防重、成图逐项验收。

该 Skill 是供助手执行的方法，不是独立图像模型或后台服务。实际执行需要使用者环境中的图片工具或 ComfyUI。没有图片时只能提供带明确缺项的模板，不能声称已验证实物细节。

原始聊天、计算机历史日志、私人图片和本机路径均已移除。参见 [验证记录](VALIDATION.md)、[发布范围](PUBLICATION.md)。
